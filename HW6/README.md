## Кратко о системе

- **Интерфейсы**: web-UI для пользователей и отдельный интерфейс для загрузки/актуализации НД.
- **Возможности**: интеллектуальный подбор НД под комплексную задачу и автозаполнение
  стандартных отчётов по данным пользователя.
- **Безопасность**: разделение доступа на уровне векторной БД, шифрование чанков,
  Guardrails + PII Sanitizer, единый шлюз к выделенному инференсу LLM.
- **Качество**: предполётная проверка индекса и атомарное переключение, онлайн-оценка
  релевантности, тестирование Ragas/DeepEval.
- **Наблюдаемость**: отдельные контуры AI-наблюдаемости и инфраструктурного мониторинга;
  дашборды Grafana с Golden Signals и AI-метриками (tokens, cost per request, качество).

## Диаграммы

Все схемы встроены в документы как изображения (PNG) со свёрнутым mermaid-исходником.
Дополнительно доступны векторные версии и исходники Graphviz:

- `diagrams/*.png` — растровые изображения (встроены в документы).
- `diagrams/*.svg` — векторные версии (масштабируются без потери качества).
- `diagrams/src/*.dot` — исходники Graphviz (единый стиль, тема).
- `mockups/grafana_dashboard.png` — мокап дашборда Grafana (встроен в §3.3 отчёта),
  исходник — `mockups/grafana_dashboard.html`.

Регенерация изображений:

```bash
for f in diagrams/src/*.dot; do
  b=$(basename "$f" .dot)
  dot -Tsvg -Gdpi=110 -o "diagrams/$b.svg" "$f"
  dot -Tpng -Gdpi=200 -o "diagrams/$b.png" "$f"
done
```
